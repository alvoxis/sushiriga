# Данные меню

**Источник:** публичное меню https://www.sushiriga.lv/menu (снято 2026-10-08).
Сайт используется только как источник данных: его HTML, CSS, дизайн и изображения не копируются,
в runtime он не используется. Скрипты импорта — `scripts/menu-import/`.

## Что перенесено

| Поле              | Откуда                                                             |
| ----------------- | ------------------------------------------------------------------ |
| `name`, `number`  | название позиции; номер («31.», «40.») вынесен в `number`          |
| `price`           | цена, переведена в центы (`€9.50 → 950`)                           |
| `ingredients`     | состав на lv / ru / en — **дословно**, с опечатками источника      |
| `description`     | описательные тексты (Snacks, «84. Philadelphia 1+1» и т. п.)       |
| `components`      | состав сетов и миксов — строки дословно                            |
| `pieces`          | только если указано явно («32GAB», «6 gab», «16+16»)               |
| `weight`/`volume` | только если указано явно («180 g», «0.33l»)                        |
| `tags`            | метки источника: Hot, WARM, Featured; «+ souse» → `includes-sauce` |

**Итого:** 99 позиций в 13 разделах (12 категорий проекта + скрытый `poke`).

## Что сознательно оставлено пустым

- `spicy`, `vegetarian` — в источнике не отмечены. Название не показатель («Vega Burger» содержит крабовые палочки).
- `allergens` на уровне товара — не опубликованы. Есть только общая фраза
  «Visi suši var saturēt A1;A2;A3;A4;A6;A7;A10;A11» → `SUSHI_MAY_CONTAIN`.
- `image` — фотографий нет, используются нейтральные плейсхолдеры.
- `pieces` для роллов и для «Azoshi Set 64G» (непонятно, что значит «64G»).

## Нормализация (без изменения смысла)

- Регистр названий приведён к Title Case (`PHILADELFIA ClASSIC` → `Philadelfia Classic`); написание сохранено.
- Удалён артефакт конструктора Wix «Copy of …» (French Fries 230 g, Nuggets 9 gab).
- `BBQ` оставлен заглавными.
- Аллерген A1: в источнике ru/en «Хлопья / Flakes» — заменено на корректное
  «Злаки, содержащие глютен / Cereals containing gluten» (официальный список ЕС).
