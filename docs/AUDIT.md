## Что осталось и что нужно извне

### Нужны доступы / решения владельца

- **Stripe**: ключи (сначала test), вебхук на `https://<домен>/api/stripe/webhook`, домен для
  Apple Pay. Код готов и проверен без сети Stripe (настоящая проверка подписи SDK, заглушка API в
  тестах); **настоящий платёж тестовой картой не выполнялся** — `e2e-server/stripe.spec.ts`
  запустится автоматически с test-ключами.
- **Хостинг, домен, TLS**: сайт не развёрнут. Docker-образ локально не собран (Docker Hub
  ограничил запросы из песочницы, HTTP 429) — добавлен CI-джоб, который собирает образ, запускает
  его и проверяет. Нужны: сервер/PaaS с постоянным томом для SQLite и резервным копированием,
  HTTPS (за прокси — `TRUST_PROXY=1`).
- **Юридические страницы**: политика конфиденциальности (собираются имя, телефон, e-mail — GDPR),
  условия заказа и возврата, реквизиты компании. Тексты должен дать владелец; Stripe также требует
  их на сайте.
- **Данные владельца**: телефон и e-mail точки, аллергены, вычитка текстов меню
  (`docs/MENU_DATA.md`), максимальные чаевые.
- **Учётные записи персонала**: создаются CLI на сервере после развёртывания.

### Ограничения, известные и принятые

- Проверен только Chromium (desktop + эмуляция Pixel 7). Safari/iOS и Firefox не проверялись —
  движки не установлены в среде (проект WebKit включается `PW_WEBKIT=1`).
- SPA без SSR: поисковики видят содержимое после выполнения JS; описание страниц общее.
- Неоплаченные заказы не удаляются автоматически (персонал видит их во вкладке «Не оплачены» и
  может отменить).
- Лимиты запросов — в памяти одного процесса (для нескольких инстансов нужен общий Redis).
- Автоматические проверки доступности находят часть проблем; ручная проверка экранными чтецами
  не проводилась.

## Готовность к запуску

Технически готово для **развёртывания на staging** (код, backend, база, админка, оплата в коде,
тесты, CI). Для **публичного запуска с приёмом денег** не хватает: ключей Stripe и проверки
платежа в test mode, хостинга с HTTPS и доменом, юридических страниц и данных владельца.
